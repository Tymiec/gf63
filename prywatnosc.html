Polityka prywatności

GF63 Server Integrations to prywatne narzędzie z jednym użytkownikiem, właścicielem serwera.

  • Aplikacja korzysta z Google Calendar API i Google Tasks API wyłącznie po to, by odczytywać, dodawać, zmieniać i usuwać wydarzenia oraz zadania na koncie właściciela.
  • Dane z kont Google nie są sprzedawane, udostępniane ani przekazywane osobom trzecim i nie są używane do reklam ani do trenowania modeli.
  • Tokeny dostępu są przechowywane tylko na serwerze właściciela. Dostęp można w każdej chwili cofnąć na myaccount.google.com/permissions.

Korzystanie z informacji otrzymanych z interfejsów API Google jest zgodne z Google API Services User Data Policy, w tym z wymaganiami Limited Use.

Privacy policy (EN)

Single-user private tool. Google Calendar and Tasks data is used only to read and manage the owner's own events and tasks, is never sold or shared with third parties, and is not used for advertising or model training. Tokens are stored only on the owner's server. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
